1 Goal

Step 7 publishes version 0.1.0 of the repo as dinov3-mlx on the GitHub account of the user (github.com/oilst/dinov3-mlx). Users get a public API that gives frame embeddings and patch embeddings of all six model sizes from uint8 RGB frames, with one line of setup. The README shows how to install it, how to get access to the weights, the results of Steps 2 to 6d and their limits. CI runs the tests that need no weights on each push. The public history holds no private string and no company name, and each commit id that the docs cite is valid.

The step ends when the repo is public, CI passes, the README shows the results, and the tag v0.1.0 exists.

2 DINOv3 topic

The roadmap row gives no new DINOv3 part. The Learn stage writes docs/learn/07-public-api.html: the path of one video frame through the public API. It covers the preprocessing contract of the Hugging Face image processor of DINOv3 (224 × 224 px, bilinear resize with antialiasing on float values, ImageNet mean and standard deviation), the TF32 probe, the padded last batch, the token split into the frame embedding and the patch embeddings, and why the default dtype mode is fp16-autocast (Table 2 of explore.html).

3.2 The TF32 probe (a refinement of D2e)

tf32_enabled reads the environment variable. When a user ran mlx before import dinov3_mlx, mlx can use TF32 while the variable now says 0. So the Embedder checks the real state once: a 64 × 64 fp32 matmul on the GPU whose exact result needs more than the 10-bit mantissa of TF32. If the result has the TF32 rounding, the Embedder raises TF32ModeError. The probe costs below 10 ms. Test T6 runs it in two subprocesses, one with TF32 on and one with TF32 off. This refinement is decision P1 of Section 9.

3.3 The history rewrite

  1. Clone this repo into a new folder: git clone --no-local to ~/Documents/Development/dinov3-mlx.
  2. Run scripts/rewrite_history.py --patterns <file> there. The pattern file lives outside the repo (~/.cache/dinov3-mlx/release/patterns.txt), because it holds the private strings. Each line is a literal string or a regular expression with its replacement. The script contains no private string.
  3. The script runs git filter-branch with an --env-filter (author and committer address to ueli.peter@gmail.com) and a --tree-filter. The tree filter applies the patterns to each text file, and in *.html and *.md files it replaces each token of 7 to 12 hex digits that names a commit of the old history with the first 7 digits of its new id. The new id comes from the map folder of filter-branch: each doc cites only older commits, so their new ids exist when the tree filter runs.
  4. The script then runs the checks of AC15 and AC16 and stops with an error when one fails.
  5. The new clone gets the remote origin = https://github.com/oilst/dinov3-mlx.git. This folder (dinov3-apple) keeps the old history as a private archive and gets no remote. The ignored files (CLAUDE.local.md, tests/fixtures/generated/) are copied into the new clone. Sessions after the rewrite work in the new clone (decision P2 of Section 9).

5.1 Usage

import numpy as np
from dinov3_mlx import Embedder

model = Embedder("ViT-S/16")                 # fp16-autocast, batch size 8
frames = np.stack(rgb_frames)                 # uint8, (B, h, w, 3)
frame = model.embed_frames(frames)            # (B, 384) fp32
frame = frame / np.linalg.norm(frame, axis=1, keepdims=True)   # L2 normalization, if needed
frame, patches = model.embed(frames, size=(224, 400))          # both from one forward pass

5.2 The package import

"""DINOv3 on Apple silicon with MLX."""

import os

os.environ.setdefault("MLX_ENABLE_TF32", "0")  # before the first mlx import (ADR 0005, D2e)

__all__ = ["Embedder"]


def __getattr__(name: str) -> object:
    """Import the API on first use, so a torch process that imports a module of this package
    gets no mlx (PEP 562)."""
    if name == "Embedder":
        from dinov3_mlx.api import Embedder

        return Embedder
    raise AttributeError(name)

5.3 The batch loop

def embed(self, frames: Frames, size: Size = 224, as_numpy: bool = True,
          patch_fp32: bool = False) -> tuple[Array, Array]:
    batch = as_uint8_batch(frames)                     # TypeError, ValueError (Table 2)
    height, width = input_resolution(size)             # ValueError if not a multiple of 16
    frame_parts, patch_parts = [], []
    for start in range(0, len(batch), self.batch_size):
        chunk = batch[start : start + self.batch_size]
        used = len(chunk)
        chunk = pad_to(chunk, self.batch_size)         # zero frames: one trace per resolution
        tokens = self._forward(preprocess_frames(chunk, (height, width)))
        frame_parts.append(tokens[:used, 0].astype(mx.float32))
        patch_parts.append(tokens[:used, NUM_PREFIX_TOKENS:].astype(self._patch_dtype(patch_fp32)))
    frame = mx.concatenate(frame_parts)
    patches = mx.concatenate(patch_parts).reshape(len(batch), height // 16, width // 16, -1)
    return to_host(frame, patches) if as_numpy else (frame, patches)

7 Benchmarks

B1, API overhead. One worker for each configuration, through the GPU lock, after the memory check. Two forms on the same uint8 batch: api (Embedder.embed_frames or embed_patches) and direct (preprocess_frames, the compiled forward pass and mlx_embeddings). The forms rotate from round to round, 5 rounds, the budgets WARM_UP and TIMED of bench.py. The ratio is api ÷ direct of the throughput; the result is the lower median of the 5 round ratios.
