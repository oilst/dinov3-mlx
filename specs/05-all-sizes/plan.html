Step 5 All sizes: Plan

Roadmap step 5. Status: approved by the agent on 2026-11-07 on behalf of the user (the user asked the agent to decide). Date: 2026-11-07.

This approval does not cover the run-rule question of D4. That question waits for the user's own answer (Section 3.8 and Section 9).

1 Goal

Step 5 extends the MLX backbone of Step 4 to all six model sizes and to fp16 and bf16. It adds SwiGLU, five dtype modes on mlx, a loader that keeps the load peak low, guards for the run rules, and a record of the token range. The step ends when all model sizes pass the parity tests on mlx, or when verify.html explains each failure (Step 5 in Section 6 of docs/plan.html). Step 6 adds speed. Step 8 adds adapters. The Step 5 code must not block these steps.

On 2026-11-06 the user asked the agent to decide. So this plan keeps the chosen options of explore.html (Table 20):

  • D1: SwiGLU as three separate nn.Linear modules with the Hugging Face names. block_parameter_names is the union of an MLP probe block and a SwiGLU probe block.
  • D2: five dtype modes on mlx. Each mode is a pair of dtypes: the matmul dtype and the stream dtype. The autocast-like modes keep the names fp16-autocast and bf16-autocast. RoPE stays in fp32. The activation computes in fp32 and rounds once.
  • D3: the plan accepts the fp16 overflow of ViT-L/16 and ViT-H+/16 in fp16-cast, as on torch-mps. A runtime xfail marks it only for the pairs with evidence (way M2).
  • D4: a guard refuses every load of ViT-7B/16 with fp32 weights. The streamed fp32 reference runs only after the user's own explicit yes (path D4-Y). Until then, path D4-N applies: the ViT-7B/16 parity rows stay deferred, and a cross-check runs as a diagnostic.
  • D5: the loader casts and evaluates one tensor at a time, then calls mx.clear_cache(). A test measures the load peak.
  • D6: the token range of all 12 configurations and of the branch outputs, for each model size and dtype mode, plus a check in fp32 against the stored hidden states.
  • D7: mlx runs ViT-S/16, ViT-S+/16 and ViT-B/16 in the default session, and all six model sizes in the slow session. ViT-7B/16 comes last.
  • D8: the checks against the stored hidden states assert in fp32 and are report only in the four fp16 and bf16 dtype modes. One block test loops over all blocks.

For this plan, the agent loaded no model, ran no test and ran no benchmark. The numbers come from explore.html, from the config.json files and the safetensors headers of the six model sizes (read on 2026-11-07 without a tensor load), and from the code.

3.2 SwiGLU (D1)

  • SwiGLU has gate_proj and up_proj (D → FF) and down_proj (FF → D), each nn.Linear(bias=config.mlp_bias). It raises NotImplementedError for an activation other than "silu". MLP keeps its NotImplementedError for an activation other than "gelu".
  • Block builds SwiGLU when config.gated is true, else MLP. The NotImplementedError of Step 4 for a gated config goes away.
  • Both feed-forward networks get the same three methods: activation, hidden and __call__. hidden(x) gives the feed-forward hidden values: the GELU output, or silu(gate) · up. The token range (D6) and the adapters of Step 8b use this one tensor.
  • activation computes in fp32 and rounds once to the input dtype. In fp32 the casts do nothing.
  • block_parameter_names returns the union of two probe blocks with all biases: one with an MLP and one with SwiGLU. The union has 20 names: the 18 names of Step 4 plus mlp.gate_proj.weight and mlp.gate_proj.bias. map_key stays without the config. A gate_proj key for an MLP model size passes map_key, and load_weights(strict=True) stops it.
  • ViT-7B/16 needs no special code for its missing q and v biases. MlxConfig.from_hf reads query_bias and value_bias false, so the backbone has no q_proj.bias and no v_proj.bias. The strict load agrees with the file.
  • A fused gate and up matmul is a Step 6 question.

3.3 Dtype modes (D2)

MLX_DTYPE_MODES maps each of the five keys of THRESHOLDS to an MlxDtypeMode: the matmul dtype and the stream dtype. MlxBackbone(config, dtype_mode) keeps the name in dtype_mode and gives the pair to Embeddings and to each Block as the plain attribute dtypes. A plain attribute is not a parameter. So load_weights, set_dtype and nn.quantize do not change it, and the model never reads its mode from a weight dtype (F1 of specs/04-mlx-port/verify.html).

linear_parameter_names(model) finds every nn.Linear module with named_modules() and isinstance. Its weight and its bias get the matmul dtype. All other parameters get the stream dtype. The load uses this set.

3.5 Loading and memory (D5)

load_mlx_backbone(model_size, dtype_mode="fp32", tf32=False, ratio=LOAD_RATIO) does these actions, in this order:

  1. Call check_run_rule(model_size, matmul dtype size, label). ViT-7B/16 in fp32 raises RunRuleError. No file read and no memory check happen before this step.
  2. If the matmul dtype is fp32: compare tf32 with tf32_enabled(). Raise TF32ModeError if they differ.
  3. Compute the need: required_mlx_load_bytes = 1.2 × the weight bytes in the matmul dtype + 4 GB (Table 5).
  4. Run the memory check with the label "{model size} mlx {dtype mode}".
  5. Set mx.set_memory_limit(need). The limit is only a guideline (R13 of Step 4), so the loader itself keeps the peak low.
  6. Read config.json into MlxConfig. Build MlxBackbone(config, dtype_mode). Its random init stays lazy and is never computed.
  7. Compute linear_parameter_names(model).
  8. Read every *.safetensors file of the folder with mx.load. The read is lazy. A missing file shows as a missing key in the strict load.
  9. Read the active memory. Call mx.reset_peak_memory().
  10. For each pair of mlx_weights(tensors, dtypes, linear): evaluate the array, then keep the pair. mlx_weights pops each tensor from the dict, maps its key, reshapes the patch weight and casts the tensor. So the loader references at most one fp32 source; MLX can release it after the next read (F4 of verify.html: up to one more fp32 source tensor for a short time).
  11. Call model.load_weights(pairs, strict=True).
  12. Delete the list of pairs. Call mx.clear_cache(). The freed fp32 buffers leave the MLX cache.
  13. Make a LoadReport: the need, the load peak (mx.get_peak_memory() − the active memory of step 9), the cache memory after step 12 and the process footprint. Keep it in the plain attribute model.load_report. Write one line with record_load_peak to the memory log.

Memory rules of the sessions:

  • A memory check runs before each model load. A load that does not fit raises InsufficientMemoryError, and the test skips with the reason.
  • tests/conftest.py keeps the session limit of 4 GB. load_mlx_backbone sets the limit to the need of each load.
  • The backbone slot holds at most one backbone, torch or mlx. It frees the previous one first and calls mx.clear_cache(). It also catches RunRuleError and skips with the reason, as a second guard.
  • After each mlx load, the backbone slot compares model.load_report with load_peak_target(model_size, dtype_mode) of tests/parity_checks.py (the formula of Table 5). A load peak above the target, or a cache above 0 bytes after the load, fails the test (pytest.fail). So the gates of Table 10 see a miss.
  • One heavy job at a time: Table 10 gives the order. ViT-7B/16 comes last in each session.
  • No ViT-7B/16 load on mlx starts before test H2 passed and job 5 of Table 10 passed its gate (R19).

3.6 Token range (D6)

run_mlx_token_range(model, pixels) runs image 0 block by block. It calls Block.attention_branch, layer_scale1, Block.ff_hidden, mlp.down_proj and layer_scale2, in the order of Block.__call__, which uses the same methods. It keeps only the largest absolute values, not the full tensors, and it evaluates one block at a time. It returns a TokenRange:

  • tokens (L + 1 values): the token sequence before block 1 and after each block.
  • tokens_where (L + 1 values): the token index of each value of tokens. 0 is the CLS token; 1 to 4 are the register tokens.
  • tokens_finite (L + 1 values): true if every value of the token sequence is finite.
  • attention, ff_hidden, ff_out (L values each): the attention branch output before LayerScale, the feed-forward hidden values, and the feed-forward branch output before LayerScale.
  • last_state: the token sequence after the last block, fp32, (5 + N, D). Test T26 compares it with run_mlx_hidden_states.

Test W7 runs it on the 12 configurations for each model size and dtype mode and writes one line for each configuration (kind "token-range"). The values are report only. A non-finite value is a result: it shows the first block that overflows. Test W8 checks the fp32 values against the stored hidden states of Step 2. scripts/token_range_table.py writes results/token-range-mlx.md.

3.12 Words for GLOSSARY.md

These terms settle with this plan. The build adds them to GLOSSARY.md as its second action (Section 3.11).

  • Matmul: one matrix multiplication of the backbone, for example in an nn.Linear module or in the patch embedding.
  • Matmul dtype: the dtype of the weights and the inputs of the matmuls in one dtype mode of mlx.
  • Stream dtype: the dtype of the residual stream, the layer norms, LayerScale, the CLS token and the register tokens in one dtype mode of mlx.
  • Residual stream: the token sequence that passes from block to block. Each branch of a block adds its output to it.
  • Autocast mode (changed): a dtype mode in which the matmuls run in fp16 or bf16, and the residual stream, the layer norms and LayerScale stay in fp32. On torch, the weights stay in fp32 and torch.autocast casts them at each matmul. On mlx, the load casts the weights of the matmuls once.
  • Branch output: the output of the attention branch or the feed-forward branch of a block, before LayerScale.
  • Feed-forward hidden values: the input of down_proj in one block: the GELU output of an MLP, or silu(gate_proj(x)) · up_proj(x) of SwiGLU.
  • Token range: the largest absolute value in the token sequence before block 1 and after each block, for one configuration.
  • Load peak: the largest MLX active memory (mx.get_peak_memory) during one model load, minus the active memory before the load. It does not include the MLX cache.
  • Run rule: one rule of the section "Run rules" of CLAUDE.md, for example: ViT-7B/16 never loads with fp32 weights.
  • Expected failure: a configuration that a test marks as xfail with a reason, because evidence shows that it cannot pass, for example the fp16 overflow.
  • Cross-check: the parity of an mlx output against a torch output in the same dtype mode, without the reference output. Report only.
  • Streamed reference: a reference output computed on torch-cpu in fp32 with the weights of one block in memory at a time.
  • Default session: a pytest session without DINOV3_SLOW. Slow session: a pytest session with DINOV3_SLOW=1.
  • Small model (changed): a Hugging Face backbone with 2 blocks and random weights (tests/small_model.py). It has the values of ViT-S/16 or of ViT-S+/16, or the shape of ViT-7B/16 at a small embedding dimension. The oracle of the part tests. It needs no gated weights.
  • Part test (changed): a test of one part of a block in mlx against the Hugging Face module on torch-cpu, with a small model.

class SwiGLU(nn.Module):
    """The feed-forward network of ViT-S+/16, ViT-H+/16 and ViT-7B/16 (D1)."""

    def __init__(self, config: MlxConfig) -> None:
        super().__init__()
        if config.hidden_act != "silu":
            raise NotImplementedError(f"activation {config.hidden_act!r} of SwiGLU")
        self.gate_proj = nn.Linear(config.dim, config.ff, bias=config.mlp_bias)
        self.up_proj = nn.Linear(config.dim, config.ff, bias=config.mlp_bias)
        self.down_proj = nn.Linear(config.ff, config.dim, bias=config.mlp_bias)

    def activation(self, gate: mx.array, up: mx.array) -> mx.array:
        """Return silu(gate) · up. It computes in fp32 and rounds once to the dtype of gate."""
        product = nn.silu(gate.astype(mx.float32)) * up.astype(mx.float32)
        return product.astype(gate.dtype)

    def hidden(self, x: mx.array) -> mx.array:
        """Return the feed-forward hidden values silu(gate_proj(x)) · up_proj(x)."""
        return self.activation(self.gate_proj(x), self.up_proj(x))

    def __call__(self, x: mx.array) -> mx.array:
        """Return down_proj(silu(gate_proj(x)) · up_proj(x)), as DINOv3ViTGatedMLP."""
        return self.down_proj(self.hidden(x))

# hidden(x) = activation(up_proj(x)); __call__(x) = down_proj(hidden(x)).


class Block(nn.Module):
    def __init__(self, config: MlxConfig, dtypes: MlxDtypeMode = FP32) -> None:
        super().__init__()
        self.dtypes = dtypes               # a plain attribute: no parameter, nn.quantize keeps it
        self.norm1 = nn.LayerNorm(config.dim, eps=config.eps)
        self.attention = Attention(config)
        self.layer_scale1 = LayerScale(config.dim)
        self.norm2 = nn.LayerNorm(config.dim, eps=config.eps)
        self.mlp = SwiGLU(config) if config.gated else MLP(config)
        self.layer_scale2 = LayerScale(config.dim)

    def attention_branch(self, x: mx.array, cos: mx.array, sin: mx.array) -> mx.array:
        """Return the attention branch output before LayerScale, in the matmul dtype."""
        return self.attention(self.norm1(x).astype(self.dtypes.matmul), cos, sin)

    def ff_hidden(self, x: mx.array) -> mx.array:
        """Return the feed-forward hidden values: the GELU output, or silu(gate) · up."""
        return self.mlp.hidden(self.norm2(x).astype(self.dtypes.matmul))

    def __call__(self, x: mx.array, cos: mx.array, sin: mx.array) -> mx.array:
        # Autocast: a half branch output × fp32 λ gives fp32. Cast mode and fp32: one dtype.
        x = self.layer_scale1(self.attention_branch(x, cos, sin)) + x
        return self.layer_scale2(self.mlp.down_proj(self.ff_hidden(x))) + x

def mlx_weights(
    tensors: MutableMapping[str, mx.array], dtypes: MlxDtypeMode, linear: frozenset[str]
) -> Iterator[tuple[str, mx.array]]:
    """Pop each tensor, map its key, reshape the patch weight and cast the tensor.

    The weight and bias of each nn.Linear (a name in linear) get the matmul dtype, all other
    parameters the stream dtype. The arrays stay lazy: the caller evaluates one at a time (D5).
    A generator: load_weights cannot take it, so each caller gives a list of the pairs.
    """
    for name in list(tensors):
        array = tensors.pop(name)                  # drop the last reference to the fp32 source
        if (key := map_key(name)) is None:
            continue                               # the mask token
        if key == PATCH_WEIGHT:
            array = array.reshape(array.shape[0], -1)
        yield key, array.astype(dtypes.matmul if key in linear else dtypes.stream)


def load_mlx_backbone(
    model_size: str, dtype_mode: str = "fp32", tf32: bool = False, ratio: float = LOAD_RATIO
) -> MlxBackbone:
    """Load the MLX backbone of one model size in one dtype mode (Section 3.5 of the plan).

    Raises:
        RunRuleError: For ViT-7B/16 in fp32, before any file read.
        TF32ModeError: If the fp32 dtype mode asks for another TF32 state than MLX_ENABLE_TF32.
        InsufficientMemoryError: If the memory check fails.
        WeightsNotFoundError: If the weights are not on this Mac.
    """
    dtypes = MLX_DTYPE_MODES[dtype_mode]
    label = f"{model_size} mlx {dtype_mode}"
    check_run_rule(model_size, dtypes.matmul.size, label)
    if dtypes.matmul == mx.float32 and tf32_enabled() != tf32:
        raise TF32ModeError(f"set MLX_ENABLE_TF32={int(tf32)} before the first use of mlx")
    need = required_mlx_load_bytes(model_size, dtype_mode, ratio)
    check_free_memory(need, label)
    mx.set_memory_limit(need)
    folder = weights_dir(model_size)
    config = MlxConfig.from_hf(json.loads((folder / "config.json").read_text()))
    model = MlxBackbone(config, dtype_mode)
    linear = linear_parameter_names(model)
    tensors: dict[str, mx.array] = {}
    for file in sorted(folder.glob("*.safetensors")):
        tensors |= mx.load(str(file))              # lazy; a str, not a Path (R18)
    active_before = mx.get_active_memory()
    mx.reset_peak_memory()
    pairs = []
    for key, array in mlx_weights(tensors, dtypes, linear):
        mx.eval(array)                             # reads one tensor from its file and casts it
        pairs.append((key, array))
    model.load_weights(pairs, strict=True)
    del pairs
    mx.clear_cache()                               # the freed fp32 buffers leave the MLX cache
    model.load_report = LoadReport(
        need_bytes=need,
        peak_bytes=mx.get_peak_memory() - active_before,
        cache_bytes=mx.get_cache_memory(),
        footprint_bytes=read_footprint().current_bytes,
    )
    record_load_peak(label, model.load_report.peak_bytes, model.load_report.cache_bytes)
    return model

def run_mlx_token_range(model: MlxBackbone, pixels: np.ndarray) -> TokenRange:
    """Run image 0 block by block and keep only the largest absolute values (D6). Report only.

    The calls and their order are the calls of Block.__call__, so the last token sequence equals
    the last state of run_mlx_hidden_states (test T26).
    """
    def largest(t: mx.array) -> mx.array:
        return mx.abs(t.astype(mx.float32)).max()           # inf stays inf

    x = model.embeddings(mx.array(pixels[:1]))
    p = model.config.patch_size
    cos, sin = model.rope(pixels.shape[2] // p, pixels.shape[3] // p)
    states = [(largest(x), mx.argmax(mx.abs(x[0]).max(axis=-1)), mx.isfinite(x).all())]
    branches = []
    for block in model.layer:
        a = block.attention_branch(x, cos, sin)
        x = block.layer_scale1(a) + x
        h = block.ff_hidden(x)
        f = block.mlp.down_proj(h)
        x = block.layer_scale2(f) + x
        states.append((largest(x), mx.argmax(mx.abs(x[0]).max(axis=-1)), mx.isfinite(x).all()))
        branches.append((largest(a), largest(h), largest(f)))
        mx.eval(x, states[-1], branches[-1])                 # one block at a time
    return TokenRange.from_arrays(states, branches, last_state=x[0])

    tokens: np.ndarray, model_size: str, dtype_mode: str, note: Callable[[], None]

    """Record and xfail an expected fp16 overflow. Fail any other non-finite output (M2)."""
    if np.isfinite(tokens).all():
        return
    note()                                        # writes the line with the status "non-finite"
    if (model_size, dtype_mode) in EXPECTED_FP16_OVERFLOW:
        pytest.xfail(FP16_OVERFLOW)
    pytest.fail(f"non-finite output: ({model_size}, {dtype_mode}) is not an expected failure")


def run_rule_skip(model_size: str, dtype_mode: str, backend: str) -> str | None:
    """Return the reason to skip a pair that breaks a run rule on one backend, or None.

    mlx: only ViT-7B/16 in fp32 (its autocast modes have half weights). torch-mps: ViT-7B/16 in
    fp32, fp16-autocast and bf16-autocast (fp32 weights on torch).
    """
    if backend == "mlx":
        bytes_per_weight = MLX_DTYPE_MODES[dtype_mode].matmul.size
    else:
        bytes_per_weight = WEIGHT_BYTES[dtype_mode]           # bench.py: the torch weights
    try:
        check_run_rule(model_size, bytes_per_weight, f"{model_size} {backend} {dtype_mode}")
    except RunRuleError as error:
        return str(error)
    return None
# src/dinov3_apple/reference.py: path D4-Y only, after the user's own yes
@torch.inference_mode()
def run_torch_streamed(
    model_size: str, pixels: Mapping[str, np.ndarray], hidden_config: str | None
) -> tuple[dict[str, np.ndarray], np.ndarray | None]:
    """Return the reference tokens of each configuration with the fp32 weights of one block in
    memory at a time. The same classes, attn_implementation "sdpa", fp32 RoPE tables and batch
    size 1 as a full-model run, so the arithmetic is the same (D4).

    Returns:
        The tokens of each configuration, and the L + 1 hidden states of hidden_config (the state
        before block 1 and after each block), stacked as (L + 1, 5 + N, D). None if hidden_config
        is None.
    """
    shards = ShardIndex(weights_dir(model_size))     # key → file, from model.safetensors.index.json
    outer = OuterParts.from_shards(shards)           # embeddings, rope_embeddings, norm
    x = {c: outer.embeddings(torch.from_numpy(p)) for c, p in pixels.items()}
    rope = {c: outer.rope_embeddings(torch.from_numpy(p)) for c, p in pixels.items()}
    hidden = [x[hidden_config][0].numpy().copy()] if hidden_config else []
    for i in range(outer.config.num_hidden_layers):
        with torch.device("meta"):
            layer = DINOv3ViTLayer(outer.config)
        layer.load_state_dict(shards.block(i), assign=True)
        for c in x:
            x[c] = layer.eval()(x[c], position_embeddings=rope[c])
        if hidden_config:
            hidden.append(x[hidden_config][0].numpy().copy())
        del layer                                    # one block of fp32 weights at a time
    tokens = {c: outer.norm(t)[0].numpy() for c, t in x.items()}
    return tokens, (np.stack(hidden) if hidden_config else None)
