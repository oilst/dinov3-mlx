Step 4 MLX port: Plan

Roadmap step 4. Status: approved by the agent on 2026-11-06 on behalf of the user (the user asked the agent to decide). Date: 2026-11-06.

1 Goal

Step 4 builds the ViT-S/16 backbone in MLX, one part at a time, with a test for each part. It adds the key map from the Hugging Face safetensors to the MLX weights, and it adds the backend mlx to the parity tests. The step ends when ViT-S/16 on mlx passes the parity tests in fp32 on all 12 configurations. Step 5 adds SwiGLU, the other model sizes, fp16 and bf16. Step 6 adds speed. Step 8 adds LoRA. The Step 4 code must not block these steps.

On 2026-11-06 the user asked the agent to decide. So the recommended options of explore.html (Table 17) are the choice:

  • D1: mlx.nn.Module classes. Their parameter names are the keys of the safetensors file (layer.{i}.…).
  • D2: the key map runs at load time. No converted file.
  • D3: the RoPE tables come from NumPy in fp32, in the order of the Hugging Face operations, with 5 identity rows for the prefix tokens and a cache for each patch grid.
  • D4: the patch embedding cuts the NCHW pixels into patches and does one matmul.
  • D5: the attention uses mx.fast.scaled_dot_product_attention.
  • D6: a test for each part against the Hugging Face modules on torch-cpu, a check of each block against the stored hidden states, and the end-to-end parity tests. New test files. The readers of the stored files move to stored.py, which imports no torch.
  • D7: the fp32 dtype mode of mlx runs with TF32 off (MLX_ENABLE_TF32=0). The CPU stream is only a diagnostic.

A benchmark runs on this Mac while the agent writes this plan. So the agent loaded no model, ran no test and ran no GPU computation for this plan. The numbers come from explore.html, the headers of the stored files and the code. The build starts its first heavy job after the running benchmark ends.

3.3 Weights (D2)

map_key(name) gives the MLX name of one Hugging Face tensor name. It accepts both spellings of the block keys: layer.{i}.… (the safetensors file) and model.layer.{i}.… (a transformers 5 model in memory, from conversion_mapping.py). It gives None for embeddings.mask_token. It raises UnknownWeightError for any other name, for example rope_embeddings.inv_freq. mlx_weights(tensors, dtype) applies map_key, reshapes the patch embedding weight and casts each array to the dtype of the dtype mode.

load_mlx_backbone(model_size, dtype_mode="fp32", tf32=False) does these actions, in this order:

  1. For an fp32 dtype mode: compare tf32 with tf32_enabled(). Raise TF32ModeError if they differ (Section 3.6).
  2. Compute the need: required_mlx_load_bytes = load_bytes(parameter_count × bytes per value) = 1.2 × 86.4 MB + 4 GB = 4.10 GB for ViT-S/16 in fp32.
  3. Run the memory check: check_free_memory(need, "ViT-S/16 mlx fp32"). The check writes one log line.
  4. Set mx.set_memory_limit(need).
  5. Read config.json of weights_dir(model_size) into MlxConfig. A model size with SwiGLU raises NotImplementedError in Step 4.
  6. Read each *.safetensors file with mx.load(str(file)). The read is lazy.
  7. Call model.load_weights(mlx_weights(tensors, dtype), strict=True) with a list of (name, array) pairs, not with a path (R18). The strict load checks the key set and every shape.
  8. Call mx.eval(model.parameters()), so the load cost does not move into the first forward pass (R14).

3.4 RoPE (D3)

rope_tables(grid_h, grid_w, head_dim, theta) computes the frequencies, the patch-center coordinates, the angles, cos and sin in NumPy fp32, in the order of DINOv3ViTRopePositionEmbedding. It puts 5 identity rows (cos 1, sin 0) on top. The result is two fp32 arrays of shape (5 + N, head_dim). MlxBackbone.rope(grid_h, grid_w) keeps one pair of mx.array tables for each grid in _rope_cache. apply_rope casts q or k to fp32, computes x · cos + rotate_half(x) · sin and casts back to the dtype of x. For the prefix tokens the result is x · 1 + r · 0 = x, so no split and no join is necessary.

The target of test_rope_tables is the Hugging Face tables, because the reference output comes from the Hugging Face code. The difference to the Meta formula with bf16 periods is report only (Table 8 of explore.html: up to 0.0079 rad at 224 px). The Close stage changes the row test_rope_tables in Table 9 of docs/plan.html to say so. RoPE-box jittering stays out of Step 4: the attribute rope_box_jitter is False and nothing reads it yet. Step 8 decides (R17).

3.5 Patch embedding and attention (D4, D5)

patchify(pixels, 16) reshapes the NCHW pixels (B, 3, H, W) to (B, 3, Hp, 16, Wp, 16), transposes them to (B, Hp, Wp, 3, 16, 16) and reshapes them to (B, Hp · Wp, 768). The order inside one patch is channel, row, column, the same order as the reshaped weight. The token order is row-major (token n = Wp · i + j), as in flatten(2) of Hugging Face. An input resolution that is not a multiple of 16 raises ValueError. Embeddings applies the nn.Linear, then puts the CLS token and the 4 register tokens in front.

Attention splits q, k and v into 6 heads of 64 values, applies RoPE to q and k, calls mx.fast.scaled_dot_product_attention(q, k, v, scale=0.125, mask=None), merges the heads and applies o_proj. There is no explicit attention in src/. Two oracles check the attention: the Hugging Face module on torch-cpu, and NumPy in float64 for the kernel alone.

3.6 Dtypes and TF32 (D7)

  • Step 4 has one dtype mode: MLX_DTYPE_MODES = {"fp32": mx.float32}. Each key is also a key of THRESHOLDS and DTYPE_OF_MODE, so the parity thresholds and the baseline join of Step 6 work without new code.
  • MLX reads MLX_ENABLE_TF32 once, at its first use, into a static value. The default is 1 (TF32 on). The fp32 dtype mode needs 0. tests/conftest.py sets MLX_ENABLE_TF32=0 before its first import of mlx. The benchmark driver sets the value in the environment of each mlx worker. The code in src/ does not change the environment.
  • tf32_enabled() reads the environment as MLX does. load_mlx_backbone raises TF32ModeError when the request and the environment differ. Limit: the check sees the environment, not the static value of MLX. A process that changes the environment after its first mlx matmul defeats the check. The TF32 probe test measures the real effect.
  • Diagnostic: with DINOV3_MLX_DEVICE=cpu the backbone fixture calls mx.set_default_device(mx.cpu). The build uses it only when a parity test fails on the GPU. A pass on the CPU points to a kernel. A fail on the CPU points to the port.
  • Step 5 needs (R6): the RoPE tables stay fp32 and apply_rope casts back. run_mlx casts the fp32 pixels to the dtype of the mode, because mx.array of a float64 array gives fp32 without a message. An fp16 array times an fp32 array gives fp32 in MLX, so Step 5 casts lambda1 explicitly. No part has a fixed dtype in its code, so an fp32 residual stream is a Step 5 option.

3.7 Memory and run rules

  • Memory check before each model load: load_mlx_backbone calls check_free_memory with the need of Section 3.3. A load that does not fit raises InsufficientMemoryError, and the test skips with the reason.
  • MLX memory limit: tests/conftest.py sets mx.set_memory_limit(4 GB) at the start of the session. The tests without the gated weights need less than 100 MB. load_mlx_backbone then sets the limit to the need of its load. Each mlx subprocess of a test sets its own limit of 1 GB (T24). The MLX limit is soft (R13), so the memory check stays the main guard.
  • One model in memory: the backbone slot of Step 2 holds at most one backbone, torch or mlx. A new load frees the previous one first. free() also calls mx.clear_cache().
  • One heavy job at a time: the test session with the weights, the TF32 probe and the benchmark run one after the other. None of them starts while another benchmark runs on this Mac.
  • The benchmark driver of Section 7 checks the machine state and the free memory before each worker, and starts each worker in its own subprocess. The torch workers get the MPS watermarks 0.8 and 0.6.

# src/dinov3_mlx/mlx_weights.py
DROPPED_KEYS = frozenset({"embeddings.mask_token"})  # training only
PATCH_WEIGHT = "embeddings.patch_embeddings.weight"
OUTER_KEYS = frozenset({"embeddings.cls_token", "embeddings.register_tokens", PATCH_WEIGHT,
                        "embeddings.patch_embeddings.bias", "norm.weight", "norm.bias"})
# layer.{i}.… in the safetensors file, model.layer.{i}.… in a transformers 5 model in memory.
BLOCK_KEY = re.compile(r"(?:model\.)?(layer\.\d+\.[a-z0-9_.]+\.(?:weight|bias|lambda1))")


class UnknownWeightError(KeyError):
    """A tensor name of the weights has no place in the MLX backbone."""


def map_key(name: str) -> str | None:
    """Return the MLX parameter name of one Hugging Face tensor name, or None for a dropped tensor.

    Raises:
        UnknownWeightError: If the name is not a tensor of a DINOv3 backbone.
    """
    if name in DROPPED_KEYS:
        return None
    if name in OUTER_KEYS:
        return name
    if match := BLOCK_KEY.fullmatch(name):
        return match.group(1)
    raise UnknownWeightError(name)


def mlx_weights(tensors: Mapping[str, mx.array], dtype: mx.Dtype) -> list[tuple[str, mx.array]]:
    """Return the MLX weights as (name, array) pairs for load_weights(strict=True).

    The patch embedding weight (D, 3, 16, 16) becomes (D, 768): channel, row, column, as in patchify.
    """
    pairs = []
    for name, array in tensors.items():
        if (key := map_key(name)) is None:
            continue
        if key == PATCH_WEIGHT:
            array = array.reshape(array.shape[0], -1)
        pairs.append((key, array.astype(dtype)))
    return pairs
# src/dinov3_mlx/mlx_weights.py
def load_mlx_backbone(
    model_size: str, dtype_mode: str = "fp32", tf32: bool = False, ratio: float = LOAD_RATIO
) -> MlxBackbone:
    """Load the MLX backbone of one model size after a memory check (Section 3.3).

    Raises:
        TF32ModeError: If the fp32 dtype mode asks for another TF32 state than MLX_ENABLE_TF32.
        InsufficientMemoryError: If the memory check fails.
        WeightsNotFoundError: If the weights are not on this Mac.
        NotImplementedError: For a model size with SwiGLU (Step 5).
    """
    dtype = MLX_DTYPE_MODES[dtype_mode]
    if dtype == mx.float32 and tf32_enabled() != tf32:
        raise TF32ModeError(f"set MLX_ENABLE_TF32={int(tf32)} before the first use of mlx")
    need = required_mlx_load_bytes(model_size, dtype_mode, ratio)
    check_free_memory(need, f"{model_size} mlx {dtype_mode}")
    mx.set_memory_limit(need)
    folder = weights_dir(model_size)
    model = MlxBackbone(MlxConfig.from_hf(json.loads((folder / "config.json").read_text())))
    tensors: dict[str, mx.array] = {}
    for file in sorted(folder.glob("*.safetensors")):
        tensors |= mx.load(str(file))                    # lazy; a str, not a Path (R18)
    model.load_weights(mlx_weights(tensors, dtype), strict=True)
    mx.eval(model.parameters())                          # the load cost stays out of the first call (R14)
    return model
# src/dinov3_mlx/mlx_model.py
def rope_tables(grid_h: int, grid_w: int, head_dim: int, theta: float) -> tuple[np.ndarray, np.ndarray]:
    """Return the RoPE tables cos and sin of one patch grid, each (5 + Hp · Wp, head_dim), fp32.

    The steps and their order follow DINOv3ViTRopePositionEmbedding of Hugging Face. NumPy 2 keeps
    a Python float weak, so each step stays fp32. Rows 0 to 4 are identity rows for the prefix tokens.
    """
    inv_freq = 1 / theta ** np.arange(0, 1, 4 / head_dim, dtype=np.float32)      # (head_dim / 4,)
    coord_h = np.arange(0.5, grid_h, dtype=np.float32) / grid_h
    coord_w = np.arange(0.5, grid_w, dtype=np.float32) / grid_w
    coords = np.stack(np.meshgrid(coord_h, coord_w, indexing="ij"), axis=-1).reshape(-1, 2)
    coords = 2.0 * coords - 1.0                                                     # (N, 2): y, x
    angles = (2 * np.pi * coords[:, :, None] * inv_freq[None, None, :]).reshape(len(coords), -1)
    angles = np.tile(angles, 2)                                                     # (N, head_dim)
    prefix = np.ones((NUM_PREFIX_TOKENS, head_dim), np.float32)
    return np.concatenate([prefix, np.cos(angles)]), np.concatenate([0 * prefix, np.sin(angles)])


def rotate_half(x: mx.array) -> mx.array:
    """Return (-x2, x1) for the halves x1 and x2 of the last axis (the half-split layout)."""
    half = x.shape[-1] // 2
    return mx.concatenate([-x[..., half:], x[..., :half]], axis=-1)


def apply_rope(x: mx.array, cos: mx.array, sin: mx.array) -> mx.array:
    """Rotate queries or keys. x: (B, heads, 5 + N, head_dim). cos and sin: (5 + N, head_dim), fp32.

    The rotation runs in fp32. The result has the dtype of x. The identity rows give x · 1 + r · 0 = x.
    """
    xf = x.astype(mx.float32)
    return (xf * cos + rotate_half(xf) * sin).astype(x.dtype)
# src/dinov3_mlx/mlx_model.py
def patchify(pixels: mx.array, patch_size: int) -> mx.array:
    """Cut NCHW pixels (B, C, H, W) into patches (B, Hp · Wp, C · p · p): channel, row, column.

    Raises:
        ValueError: If H or W is not a multiple of patch_size.
    """
    b, c, h, w = pixels.shape
    if h % patch_size or w % patch_size:
        raise ValueError(f"input resolution {h} x {w} is not a multiple of {patch_size}")
    hp, wp = h // patch_size, w // patch_size
    x = pixels.reshape(b, c, hp, patch_size, wp, patch_size).transpose(0, 2, 4, 1, 3, 5)
    return x.reshape(b, hp * wp, c * patch_size * patch_size)


class Embeddings(nn.Module):
    """The patch embedding and the prefix tokens: CLS token, register tokens, patch tokens."""

    def __init__(self, config: MlxConfig) -> None:
        super().__init__()
        self.patch_size = config.patch_size
        self.cls_token = mx.zeros((1, 1, config.dim))
        self.register_tokens = mx.zeros((1, config.num_register_tokens, config.dim))
        self.patch_embeddings = nn.Linear(3 * config.patch_size**2, config.dim)

    def __call__(self, pixels: mx.array) -> mx.array:
        patches = self.patch_embeddings(patchify(pixels, self.patch_size))
        prefix = mx.concatenate([self.cls_token, self.register_tokens], axis=1)
        prefix = mx.broadcast_to(prefix, (pixels.shape[0], *prefix.shape[1:]))
        return mx.concatenate([prefix, patches], axis=1)
# src/dinov3_mlx/mlx_model.py
class Attention(nn.Module):
    """Full attention over all tokens, with RoPE on the queries and keys of the patch tokens."""

    def __init__(self, config: MlxConfig) -> None:
        super().__init__()
        dim = config.dim
        self.heads = config.heads
        self.scale = config.head_dim**-0.5                       # 0.125 for head dimension 64
        self.q_proj = nn.Linear(dim, dim, bias=config.query_bias)
        self.k_proj = nn.Linear(dim, dim, bias=config.key_bias)   # no bias in ViT-S/16
        self.v_proj = nn.Linear(dim, dim, bias=config.value_bias)
        self.o_proj = nn.Linear(dim, dim, bias=config.proj_bias)

    def __call__(self, x: mx.array, cos: mx.array, sin: mx.array) -> mx.array:
        b, t, d = x.shape

        def heads(y: mx.array) -> mx.array:                       # (B, T, D) -> (B, heads, T, D / heads)
            return y.reshape(b, t, self.heads, -1).transpose(0, 2, 1, 3)

        q, k, v = heads(self.q_proj(x)), heads(self.k_proj(x)), heads(self.v_proj(x))
        q, k = apply_rope(q, cos, sin), apply_rope(k, cos, sin)
        a = mx.fast.scaled_dot_product_attention(q, k, v, scale=self.scale, mask=None)
        return self.o_proj(a.transpose(0, 2, 1, 3).reshape(b, t, d))


class LayerScale(nn.Module):
    """A learned factor for each channel."""

    def __init__(self, dim: int) -> None:
        super().__init__()
        self.lambda1 = mx.ones((dim,))

    def __call__(self, x: mx.array) -> mx.array:
        return x * self.lambda1


class MLP(nn.Module):
    """The feed-forward network of ViT-S/16, ViT-B/16 and ViT-L/16."""

    def __init__(self, config: MlxConfig) -> None:
        super().__init__()
        self.up_proj = nn.Linear(config.dim, config.ff, bias=config.mlp_bias)
        self.down_proj = nn.Linear(config.ff, config.dim, bias=config.mlp_bias)

    def __call__(self, x: mx.array) -> mx.array:
        return self.down_proj(nn.gelu(self.up_proj(x)))     # the erf form, not nn.gelu_approx (R15)


class Block(nn.Module):
    """One block: an attention branch and a feed-forward branch, each with a pre-norm, a LayerScale and a residual add."""

    def __init__(self, config: MlxConfig) -> None:
        super().__init__()
        self.norm1 = nn.LayerNorm(config.dim, eps=config.eps)
        self.attention = Attention(config)
        self.layer_scale1 = LayerScale(config.dim)
        self.norm2 = nn.LayerNorm(config.dim, eps=config.eps)
        self.mlp = MLP(config)                                  # Step 5: SwiGLU when config.gated
        self.layer_scale2 = LayerScale(config.dim)

    def __call__(self, x: mx.array, cos: mx.array, sin: mx.array) -> mx.array:
        x = self.layer_scale1(self.attention(self.norm1(x), cos, sin)) + x
        return self.layer_scale2(self.mlp(self.norm2(x))) + x
# src/dinov3_mlx/mlx_model.py
MLX_DTYPE_MODES: dict[str, mx.Dtype] = {"fp32": mx.float32}   # Step 5 adds fp16 and bf16 modes


class MlxBackbone(nn.Module):
    """The DINOv3 backbone in MLX. Its parameter names are the keys of the safetensors file."""

    def __init__(self, config: MlxConfig) -> None:
        super().__init__()
        self.config = config
        self.embeddings = Embeddings(config)
        self.layer = [Block(config) for _ in range(config.blocks)]
        self.norm = nn.LayerNorm(config.dim, eps=config.eps)
        self._rope_cache: dict[tuple[int, int], tuple[mx.array, mx.array]] = {}  # "_": no parameter
        self.rope_box_jitter = False                                             # R17, Step 8

    def rope(self, grid_h: int, grid_w: int) -> tuple[mx.array, mx.array]:
        """Return the RoPE tables of one patch grid from the cache."""
        if (grid_h, grid_w) not in self._rope_cache:
            cos, sin = rope_tables(grid_h, grid_w, self.config.head_dim, self.config.rope_theta)
            self._rope_cache[(grid_h, grid_w)] = (mx.array(cos), mx.array(sin))
        return self._rope_cache[(grid_h, grid_w)]

    def __call__(self, pixels: mx.array) -> mx.array:
        """Return all tokens after the final layer norm, (B, 5 + N, D)."""
        p = self.config.patch_size
        cos, sin = self.rope(pixels.shape[2] // p, pixels.shape[3] // p)
        x = self.embeddings(pixels)
        for block in self.layer:
            x = block(x, cos, sin)
        return self.norm(x)


def run_mlx(model: MlxBackbone, pixels: np.ndarray, dtype_mode: str) -> np.ndarray:
    """Run the backbone on stored pixels and return all tokens after the final layer norm.

    The contract of run_torch in reference.py.

    Args:
        model: A backbone from load_mlx_backbone.
        pixels: Normalized fp32 pixels with shape (B, 3, H, W), NCHW.
        dtype_mode: A key of MLX_DTYPE_MODES. It must match the dtype of the model weights.

    Returns:
        The tokens with shape (B, 1 + 4 + N, D), cast to fp32.
    """
    tokens = model(mx.array(pixels).astype(MLX_DTYPE_MODES[dtype_mode]))
    tokens = tokens.astype(mx.float32)          # a bf16 mx.array does not convert to NumPy
    mx.eval(tokens)
    return np.array(tokens)

WORKERS = [("torch-mps", None), ("mlx", False)]   # (backend, tf32); TF32 off in the fp32 dtype mode (D7)


def worker_plan(rounds: int = 3) -> list[tuple[int, int, str, bool | None]]:
    """Return (round, batch size, backend, tf32) for each worker. The order alternates from round to round (F1)."""
    plan = []
    for r in range(rounds):
        order = WORKERS[r % 2 :] + WORKERS[: r % 2]
        for batch_size in (8, 1):
            plan += [(r + 1, batch_size, backend, tf32) for backend, tf32 in order]
    return plan

The build writes each test first and sees it fail (red). The tests without the gated weights run on every machine with mlx. The tests with the weights skip with a reason when the weights, the stored files or the memory are missing. All mlx tests have the marker mlx. 6.1 Test inputs and the small model

  • The small model: DINOv3ViTModel on torch-cpu in fp32, eval mode, with the ViT-S/16 values of config.json (embedding dimension 384, 6 heads, MLP width 1,536, 4 register tokens, RoPE base 100, no k bias, eps 1e-5) and 2 blocks.
  • New random values for every parameter, seed 0. Each linear weight and the patch embedding weight: normal with standard deviation 1 / √fan_in, so each output has a scale of about 1. Each bias, the CLS token, the register tokens and the mask token: standard deviation 0.5. Each lambda1: standard deviation 0.3 (block 0 of ViT-S/16 has −0.80 to 0.10). Each layer-norm weight: mean 1, standard deviation 0.1; each layer-norm bias: standard deviation 0.1. Reason: the Hugging Face init sets the biases to 0 and lambda1 to 1. With these values, a wrong bias or a wrong LayerScale axis does not show.
  • The small MLX backbone gets the same weights from model.state_dict() through mlx_weights. This state dict has the spelling model.layer.{i}.… and the mask token, so each part test also tests the key map.
  • Pixels: normal values, seed 1, shapes (2, 3, 224, 224), (1, 3, 224, 304) and (1, 3, 304, 224). The two non-square shapes find a swap of height and width. The inputs of the 11 part tests come from run_parts of Step 3 on block 1 of the small model, so each part gets realistic inputs.
  • The six grids of the RoPE tests: 14 × 14, 28 × 28, 32 × 32, 14 × 25, 14 × 19 and 19 × 14 patches. They are the grids of the 12 configurations.
