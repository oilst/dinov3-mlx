Roadmap step 6d. Status: Verify done on 2026-11-09 by a separate agent. Build commits: e643520 and 55f4acd after the plan approval fa4803b. The commits d3b2532, 4244db1, 9dcd4fb and 343aa7b of the same range belong to Step 6b. The Learn and Close stages follow.

1 Summary

This page checks the 13 acceptance criteria of plan.html (Section 8, Table 5) against the code, the result lines and the logs. The agent did not build the step. It changed no code. It ran ruff, the default session, the slow session of tests/test_coreml.py, run 2 of the paired runs and of the two-stream run, and a parity check of 3 Neural Engine packages, one job at a time under the GPU lock. It recomputed the key numbers from results/coreml-6d.jsonl with its own script.

Result: 11 rows pass, 2 rows are partial, 0 rows fail.

  • The fix works. With rewrite version ne3 all 15 parity rows on CPU_AND_NE pass the fp16 thresholds (Step 6c: 2 of 15). The smallest values are frame 0.99983 (ViT-S+/16, 224 px), patch mean 0.99959 and patch 1st percentile 0.99377 (both ViT-H+/16, 224 px). The Verify parity check of 3 packages gives the same values as J2.
  • The guard works. All 25 packages have 0 constant concats. T15 shows that constant_concats finds the concat of the Hugging Face embeddings. T16 shows 0 of 789 wrong tokens for the ne3 embeddings on the Neural Engine, and 788 of 789 wrong tokens for the Hugging Face form.
  • The two-stream targets hold in both runs. P1: 1.324 (run 1) and 1.318 (run 2), target 1.20. P3: 1.122 (run 1) and 1.184 (run 2), target 1.10. Run 2 does not miss.
  • Partial rows. AC12: the bundle cache changed (the delete that the user approved, deviation 1 and 2). AC13: ADR 0016, the Learn section and the roadmap row are not written yet (Learn and Close stages).
  • Findings. Section 7 gives 8 findings: 0 high, 2 medium, 6 low.
